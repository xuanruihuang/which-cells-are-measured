# fate-shapes-measured-responses

Analysis code for the preprint *What happens to perturbed cells shapes the perturbation responses measured across
cellular contexts* (Xuanrui Huang, National University of Singapore).

**Code coming soon.** The repository will hold the extraction, analysis and figure scripts, together with the mapping
from every number in the paper to the script that produced it and to its output, and the record of the expectations
that were committed before each analysis ran.

The data analysed are all published; accessions are listed in the Data availability section of the preprint.
